# Voice / TTS context brief for Kuttiomp demo

## What this app is speaking

These are **historical spellings** from Roger Williams (English colonist, 1643), written with **17th-century English ears**, not modern linguistic IPA and not living Narragansett orthography.

**Never claim:** native speaker authenticity, elder approval, or “correct modern Narragansett.”

**Do claim:** “Historical written form from 1643; reconstruction for learning demo only.”

## Language family (for delivery style)

- Eastern Algonquian continuum (Narragansett / closely related to Massachusett–Wampanoag, Mohegan–Pequot).
- Williams uses English-like digraphs; accents in the seed (é, ò, etc.) mark stress/length as *he* heard them.
- Prefer **slow**, **clear**, **syllable-aware** delivery.
- Avoid cartoon “Hollywood Indian” intonation.
- Vowels: often pure (not diphthongized like modern US English).
- Final consonants: full, not swallowed.
- Stress: often on later syllables in longer forms (Williams’s acute marks can guide).

## Reading guidance for synthetic voice (heuristic, not tribal law)

| Pattern in Williams text | Suggested English TTS approach |
|---|---|
| acute accent (é, á, ó) | slightly longer / stressed vowel |
| double vowels (aa, ee, oo) | hold slightly longer |
| qu / qw | “kw” |
| ch | as in “church” unless Keepers say otherwise |
| wh | soft “hw” / “w” |
| final -uck / -uck | “uk” not “uck” like English “luck” if possible |
| nn, mm | lightly geminated (held) |
| n / m before stop | clear nasal |

## Sample phrase for voice warm-up (from demo seed)

2. Askuttaaquompsín — “How do you do?”
3. Asnpaumpmaúntam — “I am very well.”
4. Keénkaneen — “You and I.”
5. Taúbotne anawáyean — (if present) thanksgiving-related forms

## Production path

When a living speaker records a form:
1. Replace synthetic audio with their file
2. Set elderApproved / speakerAttribution
3. Drop or quarantine the Williams form if Keepers direct
