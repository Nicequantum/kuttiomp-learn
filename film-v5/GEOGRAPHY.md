# Film V5 — Geography Bible

**One continuous world.** Same wetu, same trees, same shore curve — dawn → night.

```text
        N (marsh wind)
            ↑
   [ salt marsh / canoe shore ]
            │
       water path
            │
   [ pine forest trail ] ← deer far / snare edge
            │
       forest edge
            │
   [ corn hills / three sisters ]
            │
       garden path
            │
   [ short trail under pines ]
            │
   [ WETU CLEARING ]  ← fire circle, mats, doorway
            │
       home path (return evening)
```

## Landmarks (lock)

| Landmark | Look | Acts that use it |
|----------|------|------------------|
| **Wetu** | Dome lodge, bark/reed, soft smoke, door flap | dawn, kin, meal, evening, night |
| **Clearing** | Soft earth, fern edge, coastal forest light | dawn, kin, meal, night |
| **Path corridor** | Dappled pine path, moss | prepare-path, return |
| **Corn hills** | Mound garden, green stalks, distant wetu through trees | land-corn |
| **Deep trail** | Tall pines, shafts of light | forest-trail |
| **Marsh shore** | Silver water, reeds, canoe on sand | water-shore, sky, night wide |
| **Fire circle** | Ember orange, copper dusk | evening, night |

## Spatial continuity rules

1. When leaving the clearing toward the day, travel **clearing → path → corn → forest → marsh**.
2. Return is reverse; evening/night always re-establish **wetu + fire**.
3. Camera should not invent a second wetu or opposite shore curve.
4. Time-of-day light progresses **monotonically** (cool dawn → gold day → copper dusk → indigo night).
5. Nature breathers (marsh, sky, path textures) may cut away briefly without new human faces.
